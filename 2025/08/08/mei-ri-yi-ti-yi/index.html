题目：在排序数组中查找元素的第一个和最后一个位置

题目难度： 中等    ⭐⭐⭐

给你一个按照非递减顺序排列的整数数组 nums，和一个目标值 target。请你找出给定目标值在数组中的开始位置和结束位置。

如果数组中不存在目标值 target，返回 [-1, -1]。

你必须设计并实现时间复杂度为 O(log n) 的算法解决此问题。

示例 1：
输入：nums = [5,7,7,8,8,10], target = 8
输出：[3,4]
示例 2：
输入：nums = [5,7,7,8,8,10], target = 6
输出：[-1,-1]
示例 3：
输入：nums = [], target = 0
输出：[-1,-1]

题解

提交记录

class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        vector<int> t = {-1, -1};
        vector<int> tt;
        for(int i = 0; i < nums.size(); i++)
        {
          if(nums[i] == target) tt.push_back(i);
        }
        if(tt.size() > 0) 
        {
          t.at(0) = tt.at(0);
          t.at(1) = tt.at(tt.size() - 1);
        }
        return t;
    }
};

二分法解题

CPP

class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        vector<int> t = {-1, -1};
        int leftIndex = getLeftIndex(nums, target);
        int rightIndex = getRightIndex(nums, target);

        if(leftIndex == -2 || rightIndex == -2) return t;
        else return t = {leftIndex, rightIndex};
    }

private:
    int getLeftIndex(vector<int>& nums, int target)
    {
      int left = 0;
      int right = nums.size() - 1;
      int middle;
      int leftIndex = -2;
      while(left <= right)
      {
        middle = left + (right - left) / 2;
        if(nums[middle] < target) left = middle + 1;
        else if(nums[middle] > target) right = middle - 1;
        else 
        {
          right = middle - 1;
          leftIndex = middle;
        }
      }
      return leftIndex;
    }

    int getRightIndex(vector<int>& nums, int target)
    {
      int left = 0;
      int right = nums.size() - 1;
      int middle;
      int rightIndex = -2;
      while(left <= right)
      {
        middle = left + (right - left) / 2;
        if(nums[middle] < target) left = middle + 1;
        else if(nums[middle] > target) right = middle - 1;
        else 
        {
          left = middle + 1;
          rightIndex = middle;
        }
      }
      return rightIndex;
    }
};

题目：x的平方根

题目难度： 简单    ⭐

给你一个非负整数 x ，计算并返回 x 的 算术平方根 。由于返回类型是整数，结果只保留 整数部分 ，小数部分将被 舍去 。
注意：不允许使用任何内置指数函数和算符，例如 pow(x, 0.5) 或者 x ** 0.5 。

示例 1：
输入：x = 4
输出：2

示例 2：
输入：x = 8
输出：2
解释：8 的算术平方根是 2.82842…, 由于返回类型是整数，小数部分将被舍去。

提示：0 <= x <= 231 - 1

题解

提交记录

CPP

class Solution {
public:
    int mySqrt(int x) {
      int sqrt;
      if(x == 0 || x == 1) return x;
      else{
        for(int i = 0; i <= x; i++)
        {
          if((long long)i * i > x) 
          {
            sqrt = i - 1;
            break;
          }
        }
      }
      return sqrt;
    }
};

cpp二分查找

class Solution {
public:
    int mySqrt(int x) {
      if(x == 0 || x == 1) return x;
      int sqrt;
      int left = 0;
      int right = x/2;
      int middle;

      while(left <= right)
      {
        middle = left + (right - left) / 2;
        if((long long)middle * middle > x)
        {
          right = middle - 1;
        }
        else if((long long)middle * middle < x)
        {
          left = middle + 1;
          sqrt = middle;
        }
        else return middle;
      }
      return sqrt;
    }
};

优秀题解

袖珍计算器算法

使用自然对对数 e 进行换底
$$\sqrt{x}=e^{\frac{1}{2}\ln x}$$

注意⚠️：通常计算机存储浮点数采用IEEE 754，且无法存储精确的浮点数值，指数函数和对数函数返回值均为浮点数，因此运算过程会存在误差。
由于向下取整，因此数值可能偏小
在得到结果的整数部分 ans 后，我们应当找出 ans 与 ans+1 中哪一个是真正的答案

CPP
class Solution {
public:
    int mySqrt(int x) {
      if(x == 0){
        return 0;
      }
      int ans = exp(0.5 * log(x));  //转换成整数为向下取整
      return (long long)(ans + 1) * (ans + 1) <= x ? ans + 1 : ans;
    }
};
复杂度分析
  • 时间复杂度：O(1)，由于内置的 exp 函数与 log 函数一般都很快，我们在这里将其复杂度视为 O(1)
  • 空间复杂度：O(1)

牛顿迭代

牛顿迭代法可以快速求解函数过零点
原理：泰勒级数
设函数为：
$$y=f(x)=x^2-C$$

1. 选择\(x_0=C/2\)作为初始值
2. 每一步迭代中，通过当前的交点\((x_i,x_i^2-C)\)，做一条斜率为 \(f^{‘}(x_i)=2x_i\)的直线：

$$ \begin{aligned} y_i &=2x_i(x-x_i)+x_i^2-C\\ &=2x_ix-(x_i^2+C) \end{aligned} $$

3. \(y_i\)与横轴的交点为\(x_{i+1}\)：
$$x_{i+1}=\frac{1}{2}(x_i+\frac{C}{x_i})$$

当\(x_k\)的值与真实的零点\(\sqrt C\)足够接近，既可作为答案

class Solution {
public:
    int mySqrt(int x) {
        if (x == 0 || x == 1)
            return x;
        double x0 = x / 2;
        while (true) {
            double xi = 0.5 * (x0 + x / x0);
            if (fabs(x0 - xi) < 1e-7)
                break;

            x0 = xi;
        }
        return int(x0);
    }
};

题目：有效的完全平方数

题目难度： 简单    ⭐

给你一个正整数 num 。如果 num 是一个完全平方数，则返回 true ，否则返回 false 。
完全平方数 是一个可以写成某个整数的平方的整数。换句话说，它可以写成某个整数和自身的乘积。

不能使用任何内置的库函数，如 sqrt 。

示例 1：
输入：num = 16
输出：true
解释：返回 true ，因为 4 * 4 = 16 且 4 是一个整数。

示例 2：
输入：num = 14
输出：false
解释：返回 false ，因为 3.742 * 3.742 = 14 但 3.742 不是一个整数。

优秀题解

规律：
$$1,2^2=4=1+3,3^2=9=1+3+5\cdots$$

class Solution {
public:
    bool isPerfectSquare(int num) {
         int num1 = 1;
        while(num > 0) 
        {
            num -= num1;
            num1 += 2;
        }
        return num == 0;
    }
};

备注

防止大数溢出

int middle = (left + right) / 2;

int一般是32位有符号整数，取值范围大约为 \(-2^{32} \sim 2^{32}-1\)
如果 left 和 right 太大了，那么 (left + right) 会溢出，产生错误
因此做一下处理

int middle = left + (right - left) / 2;

IEEE 754

是浮点数标准：定义了浮点数在计算机内的存储格式 、运算规则、舍入方式以及特殊值表示
广泛用于硬件浮点单元（FPU）、编程语言（如 C/C++、Java、Python）中

浮点数 = 符号位（sign） + 阶码（exponent）+ 尾数/有效数字（mantissa/fraction）

常见格式

格式 总位数 符号位 指数位 尾数位 范围 精度 示意
float 32 1 8 23 \(\sim\pm 3.4^{38}\) 7位有效
double 64 1 11 52 \(\sim\pm 1.8^{308}\) 15位有效

以float \(0.15625_{10}\)为例，转换为二进制\(0.00101_2\)，小数点左边只能有一个1，科学计数法为：
$$0.00101_2=1.01_2*2^{-3}$$
小数部分：\(.01_2\)
指数部分：-3
最终在内存中的存储结果就是如下图：

指数位（exponent）：-3 + 偏移量（bias）,在单精度浮点数中偏移量是127，因此127+(-3)=124，所以偏移指数是124
